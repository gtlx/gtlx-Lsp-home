# 桌面调教 (LauncherTweaks)

LSPosed / Vector 模块，给系统桌面加各种实用功能。

## ✨ 功能

### 已实现
- **180° 反向竖屏解锁** — Launcher 默认锁了方向，倒过来也能用桌面

### Roadmap（未来可加）
- 桌面网格行列数自定义
- 图标大小/标签自定义
- 隐藏应用
- 双击锁屏
- 上滑搜索/全局手势
- 更多 Launcher3 定制

## 📦 安装

1. 确保手机有 LSPosed / Vector 框架
2. 安装 APK
3. 在模块管理器中启用，作用域选择桌面（com.android.launcher3）
4. 重启桌面（或重启系统）
